# Depth Lock

Android lock-screen clock design tool.

## Current version
- Select an image only as the design canvas; the app does **not** set the system wallpaper.
- Move the clock freely by dragging it directly on the preview.
- Also control clock size, X/Y position, opacity, letter spacing, color, 12/24-hour format, weight, and font.
- Scrollable controls so every option remains reachable on smaller screens.
- Save the finished design as a PNG to the gallery.

## Build
Use the included GitHub Actions workflow: Actions → Build DepthLock APK → Run workflow.
